Regions

    None yet. Click on the frame to start one.

    What to mark

    Trace each structure that hides a robot, as this camera sees it — the hub tower, a trench, a wall. Its outline in the picture is the hidden region.

    One shape per structure. Two towers are two regions, not one: the code rebinds a track that vanishes at a structure to one that reappears anywhere else on that same structure, so it has to know which edges belong together.

    Don't mark entries and exits — the edges of the shape are the entries and exits.

    Don't mark the edge of the picture or parts of the field the camera can't see. That is handled separately; marking it here would rebind robots that simply drove out of frame.

    Rough is fine. A track ending within about a robot width of the outline counts, so a few pixels either way costs nothing. This is not calibration.

    Lines, for where robots leave the picture. A corner or the lip of the frame is not something a robot goes behind, so there is no shape to close — place two or more corners along it and press Finish line (or Shift+Enter). Mark each exit as its OWN line: a robot leaving near-left and returning far-right is not the same event, and one line around the whole frame would let a team reappear anywhere.

    Drawing

    Click to place corners.
    Enter or double-click closes the shape.
    Esc cancels it. Backspace drops the last corner.
    Drag a corner to adjust. Click a shape to select it.

    Save

    Send goes to the relay, where rtrack.relay wait-occl picks it up into robot-tracker/calib/. Download is the fallback when there is no relay -- on a phone the file lands somewhere the pipeline cannot reach.
